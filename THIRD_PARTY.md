# Third-party assets

- Three.js **0.181.2**: copied from its npm package; MIT license in `assets/vendor/THREE-LICENSE.txt`. Local minified ES modules, no external models/textures.
- GSAP **3.14.2**, with ScrollTrigger from the same package: distributed files retain their license notices. Package README points to the [GSAP standard license](https://gsap.com/standard-license). No other GSAP plugins are shipped.
- Space Grotesk variable Latin, Instrument Serif italic Latin, IBM Plex Mono regular Latin, IBM Plex Sans Arabic regular/semibold Arabic and Latin: Fontsource packages **5.3.0**, SIL OFL 1.1. Each family's license and source record is in `assets/fonts/`.
- Project previews (English/Arabic), abstract portrait, sculpture fallback and favicon: original SVG artwork created for this project using `scripts/artwork.py`. All represented applications are illustrative concepts.
- Playwright, axe and Lighthouse are optional QA tools installed outside the deployed source. They are not browser runtime dependencies.

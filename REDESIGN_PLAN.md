# Dark tech portfolio redesign

## Audit — 15 November 2026

The existing project is a static bilingual portfolio generated by Python from
`data/portfolio.json` and `data/skills.json`, with native JavaScript enhancements.
It contains five real projects, ten localized case studies, approved screenshots,
self-hosted IBM Plex Sans Arabic, a portrait, CV, social links and a WhatsApp draft
composer. There is no delivery backend. Project technology stacks and testimonials
are undocumented; they must not be invented. Existing uncommitted changes are retained.
No applicable AGENTS.md was found.

The current paper/vermilion visual system conflicts with the supplied reference.
Several generations of CSS are concatenated, creating competing layout rules.
The hero uses a small portrait, projects lack filtering, and the contact composer
does not collect project type or email. Existing deep links and media work must survive.

This is an update to the current local repository. Existing domain/deployment
configuration stays intact; no new hosting project is required.

## Final verification

Production build: 12 pages, 68 public files, 568 artifact HTTP/link/asset checks;
ZIP matches dist exactly. Sixteen home layouts and eighty case layouts at all
eight required widths pass, with 24 axe audits and no console/page errors.
Contact, media, keyboard, reduced motion, fallback and eight data tests pass.
Lighthouse three-run performance: EN 94/90/94 (median 94), AR 91/95/91 (median 91);
accessibility, best practices and SEO 100 each. PDF HTTP bytes match the original,
but managed Chrome cancels native saving. See REDESIGN_REPORT.md for evidence,
image provenance, measurement limits and local run/deployment instructions.
